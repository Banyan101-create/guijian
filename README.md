# 古建模 Gujianmo

A browser-based parametric generator for traditional Chinese timber architecture
— halls and pagodas dimensioned from 《工程做法则例》 and 《营造法式》 rather than
from invented numbers.

The app lives in [`guijian 2/`](guijian%202/) — see its
[README](guijian%202/README.md) to run it, and [DEPLOY.md](guijian%202/DEPLOY.md)
to ship it.
